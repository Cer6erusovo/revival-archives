# 原著能力撞车黑名单

*Status: WORKING; 非全书穷举。每个新能力仍需单独二次查重。*

目标不是禁止所有相似概念，而是避免原创主角拿到原著角色已经高度占位的标志性灵异。

## 红色禁区：主角核心能力不要碰

- 鬼眼 / 视觉型高层鬼域 — 杨间核心体系。
- 无头鬼影 / 影子拼接 — 杨间后续核心体系。
- 鬼手 / 身体部位接触压制 — 杨间后续核心体系。
- 重启 / 时间回退式顶级能力。
- 遗忘 / 无法被记住 — 李乐平方向。
- 欺骗现实 / 直接改写现实规则 — 骗人鬼方向。
- 梦境主导型能力 — 鬼梦方向。
- 预知未来 — 熊文文方向。
- 哭脸 / 笑脸 — 童倩方向。
- 招魂死者 — 何银儿方向。
- 纸人分身 — 柳三方向。

## 高风险区：除非机制明显不同，不作为主角根基

- 换位、坐标错位、直接距离操控。
- 门后空间、开门传送、鬼门换皮。
- 镜面替身、镜中替换。
- 声音喊名、哭笑、诅咒音乐等声音核心能力。
- 身份伪装、存在感消失、认知删除。
- 单纯“身体部位 + 接触 = 压制厉鬼”的鬼手/鬼牙/鬼皮式再包装。
- 不动就规避袭击、死人化后不被袭击等已有强辨识规律。

## 已因撞车否决的候选

- 鬼影。
- 缺失 / 存在感。
- 错位 / 换位。
- 停顿 / 时间暂停。
- 死锁 / 关系锚定：并非因撞车否决，而是因为机制过于抽象、难以稳定书写且容易产生规则漏洞。

## 当前第一只鬼状态

第一只鬼为 **OPEN**。每个严肃候选都必须重新进行原著能力撞车检查，不能因为旧文档写得详细就自动恢复为正式设定。

七中首鬼若以声音为核心尤其高风险：敲门鬼本身已有标志性的声音媒介杀人规律，不应为主角定制一个明显克制敲门鬼的声音能力。
